# Actividad Evaluada 1: Guía de trabajo

**Objetivo de la actividad:** Que el estudiante aplique los conceptos clave de la reutilización de software mediante el uso de la programación orientada a objetos (POO) en C#. Los ejercicios cubren principios fundamentales como abstracción, encapsulación, herencia y polimorfismo, permitiendo una comprensión integral de cómo construir sistemas modulares, reutilizables y mantenibles.
